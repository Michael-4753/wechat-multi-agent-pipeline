# 公众号数据分析多Agent流水线（CrewAI版）

## 🚀 为什么选 CrewAI？

CrewAI 是目前最适合**"角色分工明确的流水线任务"**的框架：
- ✅ 定义角色（Role）+ 任务（Task）就行，不用学状态机
- ✅ 内置 Agent 间协作、任务传递、记忆管理
- ✅ 支持人在回路（Human-in-the-loop）
- ✅ 轻量，依赖少，适合快速落地

---

## 🏗️ 架构对比

| 维度 | 手写版 | CrewAI 版 |
|------|--------|-----------|
| Agent 定义 | 手写Python类 | 声明式：角色、目标、背景故事 |
| 任务传递 | JSON文件读写 | CrewAI自动管理上下文 |
| 错误处理 | 自己写try/except | 内置重试、超时 |
| 记忆管理 | 无 | 短期记忆 + 长期记忆 |
| 可扩展性 | 加Agent要改编排器 | 加Agent只需要加一行定义 |

## 📝 每个 Agent 的定义

### 1. 数据采集 Agent
- **角色**：公众号数据采集专家
- **目标**：从公众号后台准确采集用户数据和内容数据
- **工具**：浏览器自动化、Excel解析
- **输出**：结构化的原始数据JSON

### 2. 数据分析 Agent
- **角色**：数据分析师
- **目标**：计算核心指标，识别异常波动，提炼可执行的洞察
- **输入**：采集Agent的输出
- **输出**：核心指标清单 + 3条关键洞察

### 3. 报告生成 Agent
- **角色**：内容报告撰写人
- **目标**：把枯燥的数据变成好看的HTML看板和易读的周报
- **输入**：分析Agent的洞察和指标
- **输出**：手机版HTML报告 + 周报摘要文案

### 4. 推送通知 Agent
- **角色**：推送专员
- **目标**：把报告上传到飞书云空间，发私信通知用户
- **输入**：报告生成Agent的HTML文件和摘要
- **输出**：飞书消息发送成功

## ✨ CrewAI 带来的新能力

1. **自动上下文传递**：不用手动读写JSON文件，CrewAI自动把上一个任务的结果传给下一个
2. **Agent自主决策**：分析Agent可以自己判断"这个数据正不正常"，不需要你写死规则
3. **记忆能力**：可以记住上周的数据，自动做环比对比
4. **可插拔工具**：以后要加新功能（比如自动回复留言、自动生成标题），加个工具就行
5. **可视化执行过程**：CrewAI会打印每个Agent在做什么，出问题了一眼能看到
